# Проверка и демонстрация CI

## Локальная проверка отдельного клона

```sh
uv sync --locked
uv run pytest -v
uv run ruff check .
uv run python examples/demo.py
```

Python CI запускается при push и pull_request на Python 3.11 и 3.12.
Локальные протоколы examples/verification.txt и результаты GitHub Actions — разные
свидетельства. Ссылки на удалённые запуски собраны в CI_EVIDENCE.md.

## Намеренная регрессия

Ветка ci-failure-example содержит ошибку quantity - 1 при поступлении товара.
Она должна провалить существующие проверки остатка. В ci-failure-demo арифметика
исправлена отдельным коммитом. Main содержит правильное поведение.

Для проверки: поступить 10, списать 3 — ожидаемый остаток 7; попытка списать 8
отклоняется, остаток и количество записей журнала не меняются.
